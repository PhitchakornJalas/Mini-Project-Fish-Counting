# Mini-Project-Fish-Counting
โปรเจกต์นี้เป็นการพัฒนาระบบ Computer Vision สำหรับตรวจจับ ระบุพิกัดและนับจำนวนลูกปลาในบ่อเลี้ยงแบบอัตโนมัติจากภาพถ่ายความละเอียดสูง และไฟล์วิดีโอ โดยมุ่งเน้นการแก้ปัญหาวัตถุขนาดเล็กที่มีความหนาแน่นสูง การซ้อนทับกันของตัวปลา และสิ่งรบกวนในภาพ เช่น ลายน้ำตัวอักษรและลวดลายพื้นหลัง

---

## 1. การเตรียมและประมวลผลภาพ 

เนื่องจากการนำภาพความละเอียดสูงเข้าสู่โมเดลตรวจจับโดยตรงมักทำให้เกิดปัญหาความแม่นยำลดลง จึงได้ออกแบบ Pipeline การประมวลผลก่อนเข้าโมเดลดังนี้:

### 1.1 การลบลายน้ำและตัวอักษร
* **ปัญหา:** ภาพและวิดีโอจากอุปกรณ์บันทึกมีลายน้ำระบุวันเวลา พิกัด GPS และสถานที่ ซึ่งเป็นตัวอักษรสีขาวตัดขอบ มีรูปทรงแท่งคล้ายลำตัวปลา ส่งผลให้โมเดลเกิด False Positives ตรวจจับและนับตัวอักษรเป็นลูกปลาด้วยค่า Confidence สูง
* **วิธีแก้ไข:** 
  1. ใช้ฟังก์ชันแปลงภาพเป็นขาวดำ (Grayscale) แล้วกรองเฉพาะพิกเซลสีขาวสว่างจัดด้วย `cv2.threshold(gray, 235, 255, cv2.THRESH_BINARY)`
  2. ใช้ `cv2.dilate` ขยายขอบเขต Mask เล็กน้อยเพื่อครอบคลุมเงาขอบสีดำรอบตัวอักษร
  3. นำภาพเข้ากระบวนการ **Telea Inpainting (`cv2.inpaint`)** เพื่อเกลี่ยสีของน้ำและพื้นหลังข้างเคียงเข้ามาแทนที่ตัวอักษรทั้งหมดก่อนส่งเข้าโมเดล

### 1.2 การแบ่งภาพย่อยด้วย SAHI 
* **ปัญหา:** ภาพต้นฉบับมีขนาด $2048 \times 1536$ พิกเซล หากส่งเข้าโมเดลตามปกติ ตัวโมเดลจะย่อภาพ เหลือ $640 \times 640$ พิกเซล ส่งผลให้ลูกปลาที่มีขนาดเล็กสูญเสียข้อมูลเชิงโครงสร้างและพิกเซลจนเบลอ ทำให้โมเดลตรวจจับหลุดเป็นจำนวนมาก
* **วิธีแก้ไข:** 
  * นำเทคนิค **SAHI** เข้ามาตัดภาพใหญ่เป็นช่องย่อย ขนาด $640 \times 640$ พิกเซล ซึ่งตรงกับขนาดที่ใช้ฝึกสอนโมเดลพอดี
  * กำหนดระยะเหลื่อมระหว่างชิ้นย่อย ที่ $20\%$ (`overlap_height_ratio=0.2`, `overlap_width_ratio=0.2`) เพื่อป้องกันไม่ให้ปลาที่อยู่บริเวณรอยต่อของตารางหลุดการตรวจจับ
  * รวมผลลัพธ์ Bounding Box และ Mask ทั้งหมดกลับคืนสู่พิกัดภาพใหญ่โดยอัตโนมัติ

### 1.3 การจำกัดพื้นที่ตรวจจับ
* ตัดพื้นที่ขอบภาพที่ไม่เกี่ยวข้องออก เช่น ขอบอ่างเลี้ยง หรือบริเวณที่มีเสื่อรอง เพื่อป้องกันโมเดลจำแนกลายเสื่อผิดเป็นตัวปลา

## 2. การทดลองและเปรียบเทียบโมเดล

ในการทดลองได้คัดเลือกโมเดลตรวจจับทั้งกลุ่ม Instance Segmentation (YOLO) และ Real-Time Transformer (RT-DETR) มาทดสอบกับชุดข้อมูลจริง:

### 2.1 YOLOv26n-seg
* **เหตุผลที่เลือกใช้:** เป็นโมเดลกลุ่ม Segmentation รุ่นล่าสุดที่มีสถาปัตยกรรมโครงข่ายประสิทธิภาพสูง เหมาะสำหรับการแยกแยะโครงร่างของลูกปลาที่มีลักษณะเฉพาะตัว
* **การตั้งค่าใช้งาน:** ตั้งค่า `Confidence Threshold = 0.85` เนื่องจากตัวโมเดลมีความมั่นใจสูงต่อตัวปลา การตั้งค่าเกณฑ์ระดับสูงจึงช่วยกรอง Noise ตะกอนผิวน้ำ แสงสะท้อน และจุดรบกวนขนาดเล็กออกไปได้อย่างแม่นยำ
* **ผลการประเมิน:** **ทำงานได้ดีที่สุดในทุกโมเดลที่ทดสอบ** สามารถตรวจจับและนับจำนวนปลาได้อย่างแม่นยำและเสถียร
* **ข้อจำกัดที่พบ:**
  1. เมื่อปลากระจุกตัวรวมกันหนาแน่น ตัว Mask ยังมีอาการรวมกลุ่มเป็นก้อนเดียว
  2. สับสนลวดลายของเสื่อที่อยู่ขอบอ่างและนับเป็นตัวปลา เนื่องจากในชุดข้อมูลฝึกสอน ยังไม่มีภาพพื้นผิวลายเสื่อเป็นพื้นหลัง แก้ไขเบื้องต้นด้วยการ Crop ตัดขอบเสื่อออก

### 2.2 YOLOv8m-seg
* **เหตุผลที่เลือกใช้:** ขยายขนาดโมเดลขึ้นเป็นสเกล Medium โดยคาดหวังว่าโมเดลที่มีขนาดพารามิเตอร์ใหญ่ขึ้นจะช่วยแยกแยะวัตถุที่ซ้อนทับกันได้ดียิ่งขึ้น
* **การตั้งค่าใช้งาน:** จำเป็นต้องลด `Confidence Threshold = 0.45` เนื่องจากโมเดลทำนายค่าความมั่นใจต่อตัวปลาเฉลี่ยอยู่ในระดับต่ำ จึงต้องลด Cutoff เพื่อพยายามเก็บตัวปลาให้ได้มากที่สุด
* **ผลการประเมิน:** **ผลลัพธ์ต่ำกว่าเกณฑ์** โมเดลมีอาการนับพลาดและหลุดตัวปลาไปเป็นจำนวนมาก ค่าความมั่นใจต่ำ ส่งผลให้ไม่สามารถนำมาใช้นับจำนวนจริงได้อย่างมีประสิทธิภาพ

### 2.3 RT-DETR-L (Real-Time Detection Transformer)
* **เหตุผลที่เลือกใช้:** เป็นสถาปัตยกรรมกลุ่ม Vision Transformer แบบ NMS-free ออกแบบมาเพื่องาน Detection + Counting โดยเฉพาะ โดยหวังผลการจับตำแหน่งแบบ End-to-End
* **การตั้งค่าใช้งาน:** ตั้งค่า `Confidence Threshold = 0.45` เนื่องจากโมเดลมีความมั่นใจต่ำ
* **ผลการประเมิน:** **ผลลัพธ์ไม่ดี** โมเดลนับพลาดตัวปลาเป็นจำนวนมาก ความมั่นใจในการทำนายต่ำมาก ทำให้แทบไม่สามารถตรวจจับปลาได้
* **ข้อจำกัดเพิ่มเติม:** RT-DETR รองรับเฉพาะ Bounding Box ไม่มี Mask สำหรับวัดขนาดพื้นที่พิกเซลจริง และระบบ NMS-free ของตัวโมเดลขัดแย้งกับขั้นตอนการรวมภาพ ของ SAHI บริเวณรอยต่อ

## 4. แนวทางการพัฒนาในขั้นถัดไป (Future Work)

1. **เพิ่ม Negative Samples ใน Dataset:** นำภาพพื้นหลังเปล่า เช่น ลายเสื่อ ขอบอ่างพลาสติก และเงาการกระเพื่อมของน้ำ เข้าไปฝึกสอนโดยไม่มี Label เพื่อสอนให้โมเดลแยกแยะพื้นผิวหลอกตา
2. **ปรับปรุง Annotation ในบริเวณหนาแน่น:** เพิ่มตัวอย่างชุดข้อมูลและจัดทำ Label บริเวณที่มีลูกปลาว่ายเบียดเสียดกัน เพื่อเพิ่มขีดความสามารถของ Mask Head ในการตัดขอบตัวปลาที่อยู่ชิดกัน
